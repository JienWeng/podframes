# 纠正、犹豫、补充，可以是聊天的一部分

原创虚构示例。所谓公告及其内容仅用来演示谈话结构，不代表任何真实事件。

## Avoid：一个人永远提问，另一个人永远宣布正确答案

HOST_A: 这个消息意味着什么？
HOST_B: 这提醒我们，任何时候都应该保持警惕并理性判断。
HOST_A: 没错，让我们共同期待后续的发展。

## Better：先分清楚对方究竟在说什么

HOST_A: 我刚看完标题，以为这事已经结束了。
HOST_B: 等下，你看的是标题，还是后面那份说明？
HOST_A: 标题。后面那份我还没看。
HOST_B: [careful, conversational] 那先别急。说明里讲的是恢复了一个步骤，没说后面的都完成了。
HOST_A: 哦，那我刚才把两件事当成一件了。
HOST_B: 对。我们可以说有进展，其他的还得等确认。
HOST_A: 这句留着。比“全部搞定”准确多了。

## What to learn

- 不同意时指出具体分歧，不用每句都客气地“非常好的观点”。
- 主持人可以承认看漏了、停一下确认、收回一个判断，但不能编造真实经历或假装读过没打开的来源。
- 正式事件允许克制和认真，不必强行插笑话。
- 事实必须来自本期打开的来源；不要把示例中的虚构说明当素材。
